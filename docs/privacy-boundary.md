# Privacy Boundary

This public repository is designed for employer review and portfolio proof only.

## Public

- General API architecture notes.
- Public-safe examples of product normalization concerns.
- Sanitized snippets that do not expose production endpoint behavior.

## Private

- Production source code.
- Real product exports, commercial catalog data, endpoint URLs, credentials, and allowlists.
- Customer/session data and integration-specific business rules.
- Exact private response contracts used by live consumers.

## Rule

Public samples may show structure and coding style, but never live data, credentials, or direct production behavior.
