# Sample Code Plan

This directory is reserved for Phase 3 public-safe snippets. Samples will demonstrate API and transformation approach without mirroring production source code.

## Planned Areas

- `php/product-card-transformer.php` — fictional product-to-response mapping.
- `php/localized-term-normalizer.php` — generic Persian/Arabic text and digit normalization.
- `php/search-request-validator.php` — safe request defaults and bounded pagination/filter handling.

## Sample Rules

- Use fictional product names, brands, terms, images, prices, and IDs.
- Keep snippets short enough for review.
- Explain what each snippet demonstrates.
- Exclude live endpoint paths, credentials, allowlists, debug SQL, admin URLs, exact private response contracts, and production option names.
- Do not include catalog exports, customer data, logs, dumps, keys, or environment files.

## Status

No code samples are published yet. Phase 2 focuses on employer-friendly context and architecture; Phase 3 will add one to three sanitized PHP snippets.
